# Five-panel canopy explanation

This applet uses the shared viewer lifecycle and Three.js rendering resources. It displays frozen loads generated by the Rust plant, not a second JavaScript aerodynamic model. The embedded JSON is an explicit recorded explanatory dataset.

Regenerate from the repository root:

```sh
cd simulation
cargo run -q -p sim-io --example canopy_panels -- data/presets/as-built-trout-lake-sitl.json > ../viewer/apps/applets/canopy-panels/loads.json
```

The panel diagnostic kernel is also used by the dynamics solver. The generator reports the additional whole-canopy moment terms at the specified zero-rate, zero-sideslip condition. Do not reuse that reduced expression for arbitrary states.

The main wing depicts rigid geometry; the front inset depicts effective aerodynamic panel inclinations, including the empirical differential-brake tilt. Panel numbers run aircraft left to right. Arrow lengths are quantitative, with separate force and velocity scales. The enlarged local inset projects vectors into its chord-normal plane, so it omits lateral components; numerical lift/drag magnitudes include all components. Inputs are effective brake travel, after actuator/rigging effects. No physical equilibrium is asserted.

Build and publish through the normal viewer manifest with `--app canopy-panels`. Blog math remains in adjacent Markdown and uses the shared MathJax renderer.
