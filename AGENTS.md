# Repository writing conventions

Use LaTeX mathematics in explanations, research reports and articles: $...$ inline and $$ on separate lines for displayed equations. The blog renders these using its shared MathJax integration. Keep code, shell commands, file paths and literal parameter names in code formatting; do not present prose equations as code blocks.

Preserve mathematical meaning, units and numerical values during formatting changes. See docs/AGENTS.md for article-specific rendering checks. Apply this convention to new and edited explanatory content; archived raw logs and executable code are not prose mathematics.
