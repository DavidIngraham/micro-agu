# Mathematics in articles

Use LaTeX math consistently in reader-facing prose: $...$ inline and $$ on separate lines for display equations. Use aligned or cases environments for multi-line expressions. The shared blog reader renders these with MathJax; GitHub also supports dollar-delimited math.

Do not put mathematical equations or variables in inline code or text code fences. Keep executable code, parameter identifiers, commands, paths and literal program output in code formatting. Preserve equation meanings, signs, units and historical values when editing presentation.

Do not add per-article MathJax scripts or another math renderer. The blog owns the shared renderer. Check both canonical /research/ URLs and legacy article URLs after renderer changes. Long equations must scroll within their own block on mobile.
