# Historical control design data

These files are retained inputs for earlier design scripts and local experiments. They are not the selected browser controller. The current measured aircraft configuration and gain-file release are indexed by `aircraft/microagu/current.json` at the repository root.

Reusable identification and synthesis now live in the `microagu-control` package. The earlier standalone gain designer is archived under `research/archive/legacy-control/`. Existing local edits to the historical candidate files have been preserved during the layout cleanup.
